# **App Name**: PairWise Speech

## Core Features:

- Error Input Interface: Clear, concise, and accessible user interface for SLPs to input phonological errors.
- Minimal Pair Generation: Generate minimal pair targets based on the entered phonological errors using LLM to reason about speech sound distinctions.
- Maximal Pair Generation: Generate maximal pair targets based on the entered phonological errors using an AI tool for target suggestion considering phoneme properties.
- Target Pair Display: Display the generated minimal and maximal pairs in a structured format.
- Target List Saving: Enable SLPs to save generated target lists for future use.
- User Authentication: Implement a user authentication system with sign-up and login functionality.

## Style Guidelines:

- Primary color: Calming blue (#64B5F6) to promote focus and reduce stress.
- Background color: Light gray (#EEEEEE) for a clean, professional look.
- Accent color: Soft green (#81C784) to highlight important elements and provide positive feedback.
- Body and headline font: 'PT Sans' (sans-serif) for a modern and readable experience.
- Use simple, clear icons to represent different phonological processes and target types.
- A clean, well-organized layout that allows Speech Language Pathologists to easily access the resources that they need.
